# Site Paulo Adriano Team

Site estático (HTML, CSS e JS puros, sem build) em estilo Bento, com o conteúdo do PDF "Plano de Personal Trainer".

- **Número do WhatsApp:** edite a constante `WHATSAPP` no topo de `script.js` (DDI + DDD + número, só dígitos). Enquanto estiver vazia, os botões só levam à seção de contato.
- **Domínio:** o `canonical` e o Open Graph apontam para `pauloadrianoteam.com`. Ajuste no `index.html` se o domínio final for outro.
- **Imagens:** `img/` (extraídas do PDF e otimizadas).
- **Teste local:** `python3 -m http.server` dentro desta pasta.
